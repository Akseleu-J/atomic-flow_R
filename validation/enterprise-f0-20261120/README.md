Тесты по умолчанию дали **36 PASS af-cli + 32 PASS af-program**. Отдельно
прошли тест с `dev-gate`, `cargo fmt --check`, Clippy с `-D warnings` и
локальная распаковка бета-архива с проверкой Studio по HTTP. Допуск
проверяется перед началом операции. Уже принятые операции могут
завершиться после истечения окна. Маркер времени находится
в локальном каталоге состояния и не защищён от удаления этим же пользователем.
Отзыва офлайн-пропуска в этом формате нет. Автоматическое завершение
работы выводит из обращения запущенную копию бинаря и сохраняет данные,
а доступ к существующим данным остаётся возможен средствами восстановления.
